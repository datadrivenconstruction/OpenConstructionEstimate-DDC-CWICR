# CIS construction cost base

**ГЭСН / ФЕР / ТЕР (GESN / FER / TER)**

The resource-based construction norm system of Russia and the CIS: State
Elemental Estimate Norms (ГЭСН), Federal Unit Rates (ФЕР) and Territorial Unit
Rates (ТЕР). This is the founding base of the DDC CWICR collection and the largest
single base in it.

## What this base is

- Source system: the CIS resource-based estimating norms, harmonised into the
  canonical DDC CWICR format. In local markets the same methodology is known under
  national codes such as ENiR, GESN, FER, NRR, ESN, AzDTN, ShNQK, SNT, BNbD.
- Content: 55,719 work items and rates, 27,672 unique resources, described through
  labour, machine time and material consumption norms per unit of construction output.
- Applied across Central Eurasia (Belarus, Kazakhstan, Kyrgyzstan, Russia, Tajikistan,
  Turkmenistan, Uzbekistan), the Caucasus and Eastern Europe.

## Editions in this folder

The base is provided in 30 editions, each in its own `XX___DDC_CWICR/` folder, one per
language and regional pricing version (for example `EN___DDC_CWICR/`, `DE___DDC_CWICR/`,
`RU___DDC_CWICR/`, `ZH___DDC_CWICR/`). Each edition folder contains:

- the full base as parquet (canonical 95-column schema),
- the compact resource catalog as csv and xlsx,
- the vector snapshots for semantic search,
- its own README with the details for that edition.
